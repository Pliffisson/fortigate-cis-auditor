Como exportar a configuração Instruções e comandos do FortiGate

Para obter a melhor cobertura, gere a configuração completa pelo CLI do FortiGate:

get system status
config system console
    set output standard
end
show full-configuration

Salve toda a saída em um arquivo .conf. Inclua a linha Version: de get system status antes da configuração para identificar o FortiOS. Use texto UTF-8 ou Unicode, sem criptografia.

Não interrompa, filtre ou omita partes da saída. A configuração completa permite avaliar os controles aplicáveis.
